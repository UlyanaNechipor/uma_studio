# UMA Studio — код сайта

Код для сайта [umastudio.tilda.ws](https://umastudio.tilda.ws/) на Тильде.
В Тильде стоит одна вставка ([`tilda/core.html`](tilda/core.html)), всё остальное сайт загружает отсюда.
Изменение, запушенное в `main`, появляется на сайте примерно через минуту, без переопубликования страницы в Тильде.

## Как это работает

1. `tilda/core.html` вставлен в первый HTML-блок (T123) страницы. В нём то, что должно сработать
   до отрисовки: тема, блокировка скролла, прелоадер, и загрузчик.
2. Загрузчик узнаёт у GitHub API номер последнего коммита в `main`, берёт с jsDelivr файл `uma.json`
   именно этой версии, качает все файлы из него параллельно и подключает строго по порядку.
3. Если jsDelivr недоступен, пробует `fastly.jsdelivr.net` и `gcore.jsdelivr.net`.
   Если не получилось совсем, прелоадер всё равно уходит через 10 секунд.

## Структура

| Путь | Что это |
|---|---|
| `uma.json` | список файлов и **порядок** их подключения (CSS, потом JS) |
| `css/*.css` | стили, по одному файлу на эффект |
| `js/*.js` | скрипты, по одному файлу на эффект |
| `tilda/core.html` | вставка для первого блока страницы (меняется только вручную в Тильде) |
| `tilda/footer-mount.html` | вставка на место футера: футер приходит из `js/footer.js` |

Новый файл подключается только после того, как его добавили в `uma.json`.
Порядок в `uma.json` важен: последующие стили перебивают предыдущие, `theme.css` идёт последним.

## Предпросмотр перед выкладкой

1. Изменения пушатся в ветку `dev`.
2. Открыть `https://umastudio.tilda.ws/?umaref=dev`: сайт возьмёт код из `dev`. Это запоминается до закрытия вкладки.
3. Если всё хорошо, `dev` вливается в `main`. Вернуться к основной версии: `?umaref=main`.

`?umadebug` выводит лог загрузчика в консоль, а `scroll-fill.js` дополнительно показывает панель с состоянием заливки заголовков.

## Заметки для правок

- Обработчики `DOMContentLoaded` и `load` в файлах работают как обычно: загрузчик вызывает их сразу,
  если событие уже прошло.
- В DevTools ошибки показываются с путём файла (`uma/js/...`).
- ID блоков Тильды (`rec...`) зашиты в CSS и JS. Если блок в Тильде пересоздать, ID поменяется.
