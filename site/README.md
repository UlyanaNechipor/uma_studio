# Переезд с Тильды — пакет вёрстки

Всё, что нужно, чтобы собрать сайт без Тильды. Ничего из этой папки на Тильду не грузится.

| Что | Где |
|---|---|
| Тексты, контакты, навигация | `content/site.json`, `content/home.json` |
| Кейсы проектов | `projects/*.json` |
| Раскладка главной (координаты каждого элемента, десктоп 1200 / мобилка 320) | `content/layout.json` |
| Цвета, шрифты, кегли, сетка, движение | `site/styles/tokens.css` |
| Исходные картинки с Тильды (оригиналы) | `site/assets/tilda/` |
| Наши картинки (обложки, мокапы, webp) | `img/` |
| Полный слепок живого сайта (DOM, скриншоты на 7 ширинах) | ветка `export`, обновляется Action «snapshot» |

## Сборка
```
node site/build.mjs      # → site/dist — эту папку целиком заливать на хостинг
cd site/dist && python3 -m http.server 8765   # посмотреть локально
```
Без npm и зависимостей: нужен только Node 18+. Шрифт Manrope лежит в `site/assets/fonts` (лицензия OFL), Google Fonts не нужен.

Сейчас собрана главная. Сверка с Тильдой на 390 и 1440 px: высоты всех блоков совпадают с точностью до 10 px.
Пока не перенесено: анимации появления, прокрутка годов, превью проектов при наведении, страницы кейсов, 404.

## Как устроена сетка и масштабирование
Макет: десктоп 1200 px, мобилка 320 px. Все размеры в стилях записаны в пикселях макета: `calc(N * var(--u))`.

- `--u` — пиксель макета, растёт с окном **в пределах**: мобилка 320–432 px окна (1–1.35), десктоп 960–1920 px (0.8–1.6). Шире 1920 контент встаёт по центру, поля растут; на планшете мобильная раскладка не раздувается.
- Текст — `max(минимум в rem, размер макета × --u)`: мелкий текст не меньше 12 px, заголовки не меньше 80% макета, и всё растёт, если человек увеличил шрифт в браузере.
- Пиксели напрямую — только линии, скругления, поля телефона 16 px, шаг колонок 8 px, иконки.
- Десктоп: поля 32, колонки 272 / 264 / 276 / 276 с шагом 16, правая половина с 600. Мобилка: поля 16 px, две колонки с шагом 8 px.

## Кеш браузера

- `build.mjs` дописывает к каждому адресу стиля, скрипта и картинки `?v=<хеш содержимого>`. Файл изменился — адрес новый,
  и Safari/Chrome не подставят старую копию к новой странице. Не менялся — берётся из кеша без запроса.
- `site/dist/_headers` (Netlify, Cloudflare Pages) уже задаёт: страница — `no-cache`, файлы с `?v=` — на год.
  На другом хостинге то же самое: `index.html` без кеша (`Cache-Control: no-cache`), `styles/`, `scripts/`, `img/`,
  `site/assets/tilda/` — `max-age=31536000, immutable`, шрифт — неделя. Service worker не используется.
- В браузере хранится только выбранная тема (`localStorage`, ключ `uma-theme`).
- «Уменьшение движения» в настройках телефона (Универсальный доступ → Движение) отключает все анимации сайта намеренно.
