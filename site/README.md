# Переезд с Тильды — пакет вёрстки

Всё, что нужно, чтобы собрать сайт без Тильды. Ничего из этой папки на Тильду не грузится.

| Что | Где |
|---|---|
| Тексты, контакты, навигация | `content/site.json`, `content/home.json` |
| Кейсы проектов | `projects/*.json` |
| Раскладка главной (координаты каждого элемента, десктоп 1200 / мобилка 320) | `content/layout.json` |
| Цвета, шрифты, кегли, сетка, движение | `site/styles/tokens.css` |
| Исходные картинки с Тильды (оригиналы) | `site/assets/tilda/` |
| Наши картинки (обложки, мокапы, webp) | `img/` |
| Полный слепок живого сайта (DOM, скриншоты на 7 ширинах) | ветка `export`, обновляется Action «snapshot» |

## Сборка
```
node site/build.mjs      # → site/dist — эту папку целиком заливать на хостинг
cd site/dist && python3 -m http.server 8765   # посмотреть локально
```
Без npm и зависимостей: нужен только Node 18+. Шрифт Manrope лежит в `site/assets/fonts` (лицензия OFL), Google Fonts не нужен.

Сейчас собрана главная. Сверка с Тильдой на 390 и 1440 px: высоты всех блоков совпадают с точностью до 10 px.
Пока не перенесено: анимации появления, прокрутка годов, превью проектов при наведении, страницы кейсов, 404.

## Как устроена сетка
Тильда рисует десктоп на 1200 px, мобилку на 320 px и растягивает макет на ширину окна.
В токенах это `--u` = 1 px макета (`100vw / 1200` с 960 px, `100vw / 320` до 960 px).
Поля 32 / 16, правая колонка десктопа начинается с 600.
