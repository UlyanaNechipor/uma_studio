# Проекты

Обложки проектов для списка «Избранные проекты»: `<проект>-cover.webp` — мокап (ноутбук и телефон в интерьере) для превью у курсора и левой картинки карточки на телефоне; `<проект>-mood.webp` — фото в настроении проекта для правой картинки карточки. Без скругления, обрезка `object-fit: cover`.
