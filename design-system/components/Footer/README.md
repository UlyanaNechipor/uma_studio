# Footer

Подвал: крупный логотип и подпись слева, колонки «Компания» и «Контакты» справа.

- Линия `line` сверху прочерчивается слева направо за 1.3 с (`ease-line`), когда подвал доходит до экрана; колонки появляются следом.
- Логотип `d-logo-footer` / `m-logo-footer`; заголовки колонок 12 px `txt`, пункты 12 px `grey`, при наведении `txt`.
- Десктоп: «Компания» с 600, «Контакты» с ≈990. Телефон: логотип сверху, две колонки ниже, подпись внизу.
- Пока без ссылок: Телеграм и политика конфиденциальности (добавятся позже).
- Что даёт страница: пункты меню, город, почту, телефон, ссылки.
