# Header

Шапка: логотип слева, три пункта меню и переключатель темы справа; закреплена сверху, высота `header-h`.

- Фон `bg`, снизу линия `line`. Тень и прозрачность не используем: шапка непрозрачная, след курсора виден и на ней.
- Десктоп: колонки 568 / 190 / 186 / остаток / кнопка — пункт «Проекты» встаёт на `col-split` (600). Пункты 12 px, `grey`, при наведении `txt`.
- Телефон: поля 16 px, пункты 10 px с шагом 10, кнопка темы 20 px.
- Логотип — набор: WORKING 700 + TITLE 300.
- При загрузке логотип прилетает из прелоадера, затем по очереди с шагом 0.09 с появляются пункты и кнопка.
- Что даёт страница: пункты меню (якоря разделов).
