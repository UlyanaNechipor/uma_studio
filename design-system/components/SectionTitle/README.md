# SectionTitle

Подпись раздела и заголовок с заливкой: буквы проявляются слева направо из `fill-base` в `txt`.

- Подпись — 12 px, `grey`; до заголовка `label-gap-d` (24) / `label-gap-m` (16). На десктопе оба начинаются с `col-split`, кроме «О нас» (слева) и «Экспериментов» (по центру).
- Заголовок — `d-h2` / `m-h2`; главный экран — `d-h1` / `m-h1`.
- Заливка идёт строка за строкой, каждая пропорционально своей ширине; мягкий край — 0.9 кегля в пять ступеней.
- Главный заголовок заливается за 1.8 с после прелоадера; разделы — за прокруткой (верх на 85% экрана → низ на 65%), при появлении сами проходят первые 12%.
- На телефоне уже 480 px заголовок сжимает трекинг, если подходит к краю ближе 16 px (не плотнее −0.04em).
- Что даёт страница: текст; переносы строк — `<br>` в данных.
