# CoverPreview

Окошко с обложкой проекта у курсора при наведении на строки списка (десктоп, только мышь).

- 380 × 240, скругление `radius-ui`, тень `shadow-preview` — единственная тень на сайте.
- Центр окошка следует за курсором с инерцией (догоняет на 12% за кадр) и наклоняется от скорости до 5°.
- Открывается из точки: прозрачность, масштаб 0.6 → 1 и шторка от центра за 0.6 с; закрывается через 140 мс после выхода из списка — без мигания между строками.
- Внутри лента всех обложек: при переходе на соседнюю строку она прокручивается к нужной за 0.75 с по `ease-inout`, картинка «дотягивается» из 1.12.
- Что даёт страница: обложки проектов в порядке строк (`assets/Projects/*-cover.webp`).
