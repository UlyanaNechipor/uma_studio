# ProjectCard

Карточка проекта на телефоне: название и год, тип, две картинки — мокап и фото в настроении проекта.

- Ширина — поле к полю (288 в макете), шаг карточек `card-h` (203), линия `line` сверху.
- Название 14 px ПРОПИСНЫМИ, год 14 px `grey` справа; тип 14 px `grey`. Картинки в две колонки с шагом `gutter-m`, высота 79, без скругления.
- Появление: линия прочерчивается слева направо за 1.1 с, следом по очереди с шагом `dur-step` всплывают название, год, тип, левая и правая картинка; год прокручивается, как табло. Ещё раз год прокручивается, когда карточка проходит через середину экрана.
- Что даёт страница: название, тип, год, ссылку и две картинки (`assets/Projects`).
