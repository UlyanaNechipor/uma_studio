# ThemeToggle

Переключатель темы в шапке: луна в тёмной теме, солнце в светлой.

- Кнопка 24 × 24 (на телефоне 20), рамка `line`, скругление `radius-ui`; иконка — 42% кнопки, цвет `grey`.
- При наведении кнопка заливается `txt`, иконка — `bg`.
- Нажатие: от кнопки расходится круг цвета `bg` новой темы, на 45% пути тема переключается; луна поворачивается на 45° и сменяется солнцем. Выбор запоминается в браузере.
- Подпись для экранного диктора меняется: «Светлая тема» / «Тёмная тема».
