# ProjectRow

Строка проекта в «Избранных проектах» на десктопе: название, тип, год.

- Колонки: название 568 от поля, тип с `col-split`, год у правого поля. Шаг строк `row-h` (53), линии `line` сверху и под последней.
- Название `d-name` в `txt-soft`, тип и год — 12 px `grey`.
- Появление: строки целиком въезжают слева на `shift-side` с шагом `dur-row-step`.
- Наведение (только мышь, от 960 px): год прокручивается, как табло; у курсора — окошко с обложкой (CoverPreview). Сама строка не подсвечивается.
- Что даёт страница: название, тип, год, ссылку на кейс и обложку.
