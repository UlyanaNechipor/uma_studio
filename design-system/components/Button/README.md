# Button

Кнопки сайта: основная «Написать нам» с зелёной точкой и второстепенная «О нас»; рядом почта текстом.

- Размер 127 × 36 на десктопе (`btn-w`, `btn-h`), на телефоне основная 140 или во всю ширину, второстепенная 94; шаг между ними 16 / 8.
- Скругление `radius-btn` (2). Подпись 12 px, вес 500, разрядка 0.45 px. Без стрелок и иконок, кроме точки `signal`.
- Основная: `btn-bg` / `btn-fg`, при наведении `btn-bg-hover`. Второстепенная: `btn2-bg` / `btn2-fg`, при наведении `btn2-bg-hover`; в светлой теме при наведении текст светлеет.
- Наведение — только цвет, за `dur-hover` по `ease-out`. Без подъёма, тени и масштаба.
- Низ кнопок выравнивается по низу соседнего фото.
- Что даёт страница: подпись и ссылку (`mailto:` или якорь). Одна основная кнопка на блок.
